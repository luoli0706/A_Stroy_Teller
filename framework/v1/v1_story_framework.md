# 《大招只能放一次》初版 v1 全景框架

## 终极优化与逻辑补丁（Review & Fix）

### 优化点1：卡名公开与情报战平衡
卡名是高度抽象、可误导的神谕式短语。公开卡名不等于公开能力，反而会放大猜忌链与反向误导。

### 优化点2：男主特攻卡被排除威胁的合理性
神明系统按当前战斗收益评估。殊离《迟来的售后服务》仅在“神明本体在场+底层权限错乱”时可触发，前六天等同废牌，因此被各方忽略。

### 优化点3：明暗线交织与青梅之死动机闭环
沐仪七分的能力承担情感与机制双重铰链。其牺牲及能力退化析出的空牌，成为宋林萱推导终局与殊离掀桌的关键纽带。

## 一、世界观与梦核美学
- 舞台：灰界，近未来酸雾弥漫的慢性腐朽都市。
- 神临现场：第13层废墟天台，褪色棋盘砖、无指针巨钟、生锈摇摇车并列。
- 参战者：12名持牌者，其中10名精英与2名编外路人（殊离、梨微）。

## 二、核心机制
1. 一发绝响：每人只有一次发动机会。
2. 明牌盲盒：全员只知彼此卡名，不知具体效果与触发前置。
3. 空牌弑神：能力发动后析出空牌，集齐10枚可铸弑神之矛，否则全城格式化。
4. 系统盲区：殊离特攻卡因前置苛刻被判零收益。

## 四、四幕结构
1. **第1天**：天台开局，卡名公开，天道苏暴走，万离珊殒命，宋林萱黑化。
2. **第2-4天**：心理战升温，守序同盟成型，暗线情感推进。
3. **第5-6天**：伏击升级，沐仪七分牺牲，明暗线汇流。
4. **第7天午夜**：宋林萱铸矛刺神战死，梨微冻结，殊离以《迟来的售后服务》触发因果退单格式化高维系统。

## 五、v1锁定目标
- 主题：一次性大招机制下的人心选择。
- 叙事：明线高压智斗 + 暗线低温情感。
- 落点：悲壮代价后的凡人归途。
